# Assetly editorial content

The public guides use a fictional project, Harborfield Coffee, as a consistent worked example. It is an invented case for teaching file organization; it is not a customer, client, or testimonial. Do not present it as one.

The site is editorial-first. Every guide should stand on its own without an account, purchase, download, or tool. Before publishing technical facts, compare them with current primary documentation and make sure each internal link resolves.
